# Presentation deck

[`slides.md`](slides.md) is a [Marp](https://marp.app/) Markdown deck.

## Render

```bash
# HTML
npx @marp-team/marp-cli@latest deck/slides.md -o deck/slides.html

# PDF
npx @marp-team/marp-cli@latest deck/slides.md --pdf -o deck/slides.pdf
```

Or use the **Marp for VS Code** extension to preview and export.
